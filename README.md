
# DNA Reverse Complement Generator

## Overview

The **DNA Reverse Complement Generator** is a bioinformatics project developed in R to generate the reverse complement of a DNA sequence. It applies standard nucleotide base-pairing rules and basic string manipulation techniques to perform a fundamental sequence-processing task.

This project demonstrates the application of R programming to molecular biology and serves as an introduction to computational sequence analysis.

## Biological Background

DNA consists of four nitrogenous bases that follow complementary base-pairing rules:

| Nucleotide | Complement |
|---|---|
| Adenine (A) | Thymine (T) |
| Thymine (T) | Adenine (A) |
| Guanine (G) | Cytosine (C) |
| Cytosine (C) | Guanine (G) |

A reverse complement is generated by first replacing each nucleotide with its complementary base and then reversing the resulting sequence.

## Features

- Generates the reverse complement of a DNA sequence.
- Converts lowercase input to uppercase.
- Replaces characters outside the standard DNA alphabet (`A`, `T`, `G`, `C`) with `N`.
- Uses built-in R functions without external package dependencies.

## Usage

After executing the R function defined in the repository, provide a DNA sequence as input:

```r
revcomp("ATGC")
```

**Output:**

```text
"GCAT"
```

### Additional Example

**Input:**
```text
AATCCGGTAAATCG
```

**Reverse complement:**
```text
CGATTTACCGGATT
```

## Implementation

The function uses base R utilities for sequence processing:

- `toupper()` standardizes the input to uppercase.
- `gsub()` replaces characters outside the accepted DNA alphabet with `N`.
- `chartr()` performs nucleotide complement mapping.
- `strsplit()` separates the sequence into individual characters.
- `rev()` reverses the complementary sequence.
- `paste()` combines the characters into a continuous string.

## Requirements

- R

No additional R packages are required.

## Limitations

- The function is designed for single DNA sequences.
- Non-standard characters are replaced with `N`; the function does not perform comprehensive biological sequence validation.
- Ambiguous nucleotide codes beyond `N` are not explicitly supported.
